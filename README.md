## 🌐 Networking & Internet

| Acronym | Full Form | Arti & Penjelasan Singkat |
| :--- | :--- | :--- |
| **DNS** | Domain Name System | **Sistem Nama Domain**<br>Sistem yang menerjemahkan nama domain web (seperti `google.com`) menjadi alamat IP berupa angka agar bisa dipahami komputer (buku teleponnya internet). |
| **CIDR** | Classless Inter-Domain Routing | **Pengalamatan IP Tanpa Kelas**<br>Metode untuk mengalokasikan alamat IP dan merutekan paket data di internet secara lebih efisien dan fleksibel dibanding sistem kelas tradisional. |
| **IP** | Internet Protocol | **Protokol Internet**<br>Label numerik yang ditetapkan untuk setiap perangkat yang terhubung ke jaringan komputer yang menggunakan Protokol Internet untuk berkomunikasi. |
| **HTTP** | Hypertext Transfer Protocol | **Protokol Transfer Hiperteks**<br>Aturan atau protokol dasar yang digunakan untuk mengirim dan menerima data/halaman web di internet. |
| **HTTPS** | Hypertext Transfer Protocol Secure | Versi HTTP yang **aman** karena semua data yang dikirim dienkripsi (diacak) agar tidak bisa diintip orang lain. |

## 🗄️ Database & Data Management

| Acronym | Full Form | Arti & Penjelasan Singkat |
| :--- | :--- | :--- |
| **SQL** | Structured Query Language | **Bahasa Kueri Terstruktur**<br>Bahasa standar yang digunakan untuk berkomunikasi, mengambil, dan mengelola data di dalam database relasional. |
| **DBMS** | Database Management System | **Sistem Manajemen Basis Data**<br>Perangkat lunak yang digunakan untuk membuat, mengelola, dan mengontrol akses ke database (contoh: MariaDB, MySQL). |
| **RDBMS** | Relational Database Management System | DBMS yang khusus mengelola database **relasional**, di mana data disimpan dalam bentuk tabel-tabel yang saling berhubungan. |
| **CRUD** | Create, Read, Update, Delete | Empat fungsi dasar (Membuat, Membaca, Mengubah, Menghapus) yang wajib dimiliki saat mengelola data dalam aplikasi atau database. |

## 💻 Web Development & API

| Acronym | Full Form | Arti & Penjelasan Singkat |
| :--- | :--- | :--- |
| **API** | Application Programming Interface | **Antarmuka Pemrograman Aplikasi**<br>Jembatan atau penghubung yang memungkinkan satu aplikasi untuk berkomunikasi dan bertukar data dengan aplikasi lainnya secara otomatis. |
| **URL** | Uniform Resource Locator | **Lokator Sumber Seragam**<br>Alamat web lengkap yang kita ketik di browser untuk menuju ke dokumen atau halaman tertentu di internet. |
| **JSON** | JavaScript Object Notation | Format pertukaran data yang ringan, berupa teks biasa, dan sangat mudah dibaca baik oleh manusia maupun komputer. Sering dipakai saat API bekerja. |
